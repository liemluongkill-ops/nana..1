# Security

This repository contains a sanitized runtime and design snapshot. It must not
contain live credentials, private Nana data, or licensed private assets.

If you find material that appears sensitive, do not quote it in a public issue.
Contact the repository owner privately through their GitHub profile and identify
only the affected file and general category.

Do not treat placeholders, mock values, or documented safety gates as permission
to access or operate any Nana runtime.
