# Contributing

Thank you for reviewing Nana.

## Preferred Feedback

- Open an issue for architecture questions, risks, and design alternatives.
- Keep each issue focused on one subsystem or data flow.
- Explain the concrete failure mode or maintenance cost being addressed.
- Pull requests may demonstrate a proposed documentation or source change.

## Safety Boundary

Do not submit:

- Credentials, API keys, tokens, cookies, or webhook URLs.
- Personal data, conversation transcripts, or memory records.
- Real device identifiers, Discord IDs, or local network details.
- Instructions that bypass operator approval, dry-run gates, or fail-closed
  behavior.

Public contributions are reviewed manually. Nothing in this repository is
automatically executed, deployed, or synchronized into Nana.
